# Changelog

## [3.0.0] - 2026-10-22

First release from the public ProgramGarden repository. Earlier versions remain
available on PyPI.

### Changed

- Requests always use the live LS HTTP transport; the recorded-response replay
  transport is not part of this package.
- Version aligned with `programgarden`, `programgarden-core` and
  `programgarden-community` 3.0.0.
