# Changelog

## [3.0.0] - 2026-10-22

First release from the public ProgramGarden repository. Earlier versions remain
available on PyPI.

### Changed

- The CodeNode support module keeps the node declaration and its shipped import
  whitelist. Executing user code runs only on the ProgramGarden platform.
- Version aligned with `programgarden`, `programgarden-finance` and
  `programgarden-community` 3.0.0.
